# RUNTIME: Asset Candidates

This document records candidate visual assets evaluated for **RUNTIME: The Last Algorithm** according to our CC0 / permissive licensing and thematic consistency criteria.

---

## 1. Evaluation Rubric

Every candidate is evaluated across:
- **Visual quality**: /10
- **Consistency**: /10 (Matches 16x16 / 32x32 dark cyberpunk neon palette)
- **License safety**: /10 (Verified CC0 / Public Domain / OFL)
- **Ease of integration**: /10 (Spritesheet / PNG format / Raylib compatibility)
- **Educational suitability**: /10 (Supports visual clarity of DSA representations)
